# Simple Calculator

A modern calculator built using HTML, CSS, and JavaScript in a single file.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal support
- Clear (AC)
- Delete (DEL)
- Keyboard support
- Responsive design

## How to Run

1. Save the code as `index.html`
2. Open the file in any web browser

## Technologies Used

- HTML5
- CSS3
- JavaScript
